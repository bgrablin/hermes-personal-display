## Completed display change

Branch: `feat/interrupted-turn-observation`. Base: `dc0a64aa7526c1bee78c60cfa7d43b7fbf3789bc`.

Hermes now emits `agent_loop_stopped` immediately for a real running gateway turn stopped by `/stop` or the running-agent `/new` path, and for TUI/Desktop `session.interrupt`. The display observer did not register the hook, so an interrupted turn could remain visually running until a later finalizer hook arrived. The patch registers the merged hook, correlates its exact `session_key` through an alias previously observed inside the same profile, never guesses between concurrent sessions, and retains bounded `reason`, `invalidation_reason` and `platform` fields. An unaliased transport key remains a separate exact observed row.

The hook marks only the parent turn interrupted. Process, delegation-unit and subagent states remain independently observed, so surviving background work stays active instead of being falsely settled. A reduced later session finalizer cannot erase the interruption; an explicit hard failure still wins. A subsequent normal start or request clears the old interrupt detail. The resolver treats a deliberate interrupt as recent activity rather than a hard failure, while explicit failed/error/stalled outcomes, including process rows without an exit code, and nonzero process exits remain failures.

The private touch inspector adds an amber **TURN INTERRUPTED** card with the observed surface and reason. It is visibly distinct from red/error treatment and from the existing uncertain-side-effect card. Opening an interrupted session scrolls the outcome into the visible portion of the landscape panel while leaving its identity and summary immediately above. No interrupt button, attach, retry, replay or additional control authority was added. Credential-targeted redaction, inert text rendering, family separation, snapshot expiry, smaller eye and blue motes are unchanged.

Visual evidence: [synthetic interrupted-turn preview](../interrupted-turn-observation-2026-09-14.svg). It was rendered to 1200×760 PNG with Inkscape and visually inspected. It contains no production data.
