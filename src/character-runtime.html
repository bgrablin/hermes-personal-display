Runtime contract
  • Canonical kiosk runtime is the Concept B central eye/orb dashboard, built inline by mascot/app.js.
  • Display presets: quiet_watch, reasoning, planning, working, completed, waiting_input, blocked, feed_stale, night_watch, critical. They drive bounded motion variables before raw telemetry styling.
  • Named intents: glance_left, glance_right, glance_up_left, brow_pop, skeptical_squint, settle, tiny_perk, smug_nod, side_eye_hold, dramatic_sigh, slow_double_blink, sleepy_yawn, scan_sweep, sigh_wave, sleep_drift, slow_blink.
  • Motion is split into pose, gaze, blinkFace, and fx channels for explicit budgets.
  • Idle motion is restrained: breath owns root Y, calm states stay within a 1px root-Y budget, and auto intents are face/gaze only.
  • Gaze uses a saccade → hold FSM. Debug line shows current target, FSM state, intent, and root-Y budget.
  • Local-only. No CDN, no external assets. Keys 1–5 = states; space/n = random intent.
