# RGS Hermes runtime assets

These PNGs are cropped runtime copies from the local RGS_Dev / OpenGameArt asset pack selected for the Hermes Personal Display RGS prototype.

Source archive: `assets/character-candidates/modular-parts/downloads/rgs_modular_vector_characters.zip`
Source extracted root: `assets/character-candidates/modular-parts/extracted/rgs_modular_vector_characters/Free 2D Animated Vector Game Character Sprites/`
Runtime copy folder: `src/assets/rgs-hermes/`

Usage notes:
- Personal/local Hermes display prototype.
- Uses only selected modular character parts: body, head, left/right hands, eye variants, mouth variants.
- Excludes weapons, bullets, crosshairs, muzzle flashes, combat/hit/death poses, horns, and wings.
- Expressions are built from RGS eye and mouth parts, not fake primitive overlays.
